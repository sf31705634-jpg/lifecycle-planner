# Tab Grouper by Domain

ツールバーのアイコンをクリックすると、開いているウィンドウ内のタブを **ドメイン単位** で自動的にグループ化するChrome拡張機能です。

## 使い方

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダ（`tab-grouper-extension`）を選択する
4. ツールバーに追加されたアイコンをクリックすると、同じドメインのタブ（2つ以上あるもの）がグループ化される

## 動作仕様

- 同じホスト名（`www.` は無視）を持つタブが2つ以上あれば、ドメイン名をタイトルにしたグループを作成する
- 既に同名のグループが存在する場合はそこに追加する
- ピン留めされたタブは対象外
- ユーザーが手動で作った別名のグループには手を出さない（グループ名がドメイン名と一致する場合のみ操作対象）
- グループの色はドメイン名から決定するため、同じドメインは毎回同じ色になる
- 自動実行はせず、アイコンをクリックした時だけ動作する
